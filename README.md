# ลอยกระทงออนไลน์ ณ วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์
### Loy Krathong Online - Thaluang Cement Thai Anusorn Technical College

เว็บแอปพลิเคชันลอยกระทงออนไลน์แบบ Serverless พัฒนาด้วย **HTML5, Tailwind CSS, JavaScript (Vanilla ES6)** และ **Google Apps Script (GAS)** 

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### หน้าที่ 1: ท่าน้ำลอยกระทง & ปล่อยโคมลอย (Main River & Sky Pier)
- **ระบบตัวละคร & อวตาร:** อวตารการ์ตูน SVG น่ารัก 6 แบบ พร้อมเลือกแผนกวิชา
- **ระบบ DIY กระทง & โคมลอย พร้อม "รูปติดกระทง":**
  - เลือกเทมเพลตสายน้ำได้ 3 บรรยากาศ (ท่าน้ำวิทยาลัย, คืนเดือนเพ็ญ, งานวัดริมน้ำ)
  - ปรับแต่งฐานกระทง ดอกไม้ ธูปเทียน และของตกแต่ง
  - ระบบอัปโหลดรูปภาพ บีบอัดและตัดรูปเป็นกรอบวงกลมทอง/หัวใจ ปักติดบนตัวกระทงและโคมลอยแบบ Real-time พร้อมแสดงป้ายชื่อ
  - ปรับแต่งทรงโคมลอย สีโคม และลวดลายมงคล
- **ระบบคำอธิษฐาน & ส่งต่อความปรารถนาดี:**
  - ตัวนับอักษร 150 ตัว พร้อมปุ่มสุ่ม/เลือกคำอธิษฐานสำเร็จรูป 4 หมวดหมู่
  - เอฟเฟกต์พลุเฉลิมฉลองและเสียง Web Audio เมื่อกดปล่อยกระทง
  - คลิกที่กระทงหรือโคมในสายน้ำเพื่อดูรูปขนาดใหญ่ คำอธิษฐานฉบับเต็ม และกดส่งกำลังใจ ❤️
- **Dashboard & ตารางรายชื่อ:** สถิตินับจำนวนกระทง/โคมลอยแบบ Real-time พร้อมค้นหา กรองแผนก และกด Export เป็นไฟล์ CSV

### หน้าที่ 2: ซุ้มเซียมซีดิจิทัล & ดูดวง (Digital Esiimsi Booth)
- กระบอกติ้วไม้ไผ่ Interactive เขย่าได้ทั้งกดปุ่มและเขย่ามือถือจริง (Device Motion)
- ระบบสังเคราะห์เสียงเขย่ากระบอกไม้ไผ่และเสียงไม้ติ้วตกกระทบด้วย **Web Audio API**
- คำทำนายเซียมซีสไตล์เด็กอาชีวะ 20 ใบ (การเรียน ความรัก โชคลาภ)
- ปุ่มบันทึกรูปภาพใบเซียมซีขนาด 9:16 (1080x1920) ด้วย HTML5 Canvas สำหรับแชร์ลง Instagram & Facebook Stories

### หน้าที่ 3: เวทีรำวงย้อนยุค & ดนตรีสด (Retro Ramwong Stage)
- จำลองเวทีงานวัดประดับไฟราวกระพริบ
- ดนตรีไทยบรรเลงรำวงจังหวะสนุกสนานด้วย Web Audio API พร้อมปุ่มเปิด/ปิดเสียง (Mute/Unmute)
- ระบบสุ่มนักเต้นอวตารผู้ร่วมงาน 4-6 คนขึ้นไปเต้นโยกย้ายตามจังหวะบนเวที
- ปุ่มโปรยพวงมาลัย 🌺 และปรบมือเชียร์ 👏 พร้อมเอฟเฟกต์ลอยฟุ้งและตัวนับคะแนนเรียลไทม์

### ส่วนควบคุมส่วนกลาง & การสนับสนุน
- ปุ่ม Admin Settings (รหัสผ่านเริ่มต้น: `1234`) สำหรับแก้ไขชื่อสถาบัน ปี พ.ศ. แผนกวิชา และ Web App API URL

## 🚀 วิธีการติดตั้งและตั้งค่า Google Apps Script

1. สร้าง Google Sheets ใหม่ที่ [sheets.new](https://sheets.new)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. คัดลอกโค้ดจาก `Code.gs` ไปวางแทนที่โค้ดเดิมทั้งหมด
4. เลือกฟังก์ชัน `setupSheet` แล้วกด **เรียกใช้ (Run)** เพื่อสร้างชีต `Data` และโฟลเดอร์ใน Google Drive อัตโนมัติ
5. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้ใหม่ (New deployment)**
   - ชนิด: **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. นำ Web App URL ที่ได้ไปใส่ในปุ่มตั้งค่า (Admin Settings) ในหน้าเว็บ `index.html`
